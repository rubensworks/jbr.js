    Class ExperimentLargeRdfBench

    An experiment instance for LargeRDFBench, a benchmark for SPARQL endpoint federation, using either its full datasets, or a sample of them over which the queries produce the same results.

      Parameters

      • zenodoRecord: string

        The Zenodo record of the LargeRDFBench Interoperable Edition to download from.

      • datasets: string[]

        The datasets to include, by their name in the Zenodo record.

      • queries: string[]

        The queries to include, by their name in the Zenodo record.

      • sample: boolean

        If the datasets must be sampled. Otherwise, the full datasets are used, as HDT files.

      • sampleSubjectRates: Record<string, number>

        The fraction of subjects to sample per dataset, which defaults to 1.

      • sampleOtherTriplesRate: number

        The fraction of the triples of sampled subjects that match no query pattern to keep.

      • sampleSeed: string

        The seed for sampling.

      • sampleValidate: boolean

        If the queries must be validated to produce the same results over the sample as over the full data.

      • generationQueryTimeout: number

        The timeout in seconds of the queries over the full data during sampling.

      • hookSparqlEndpoint: Hook

        The SPARQL endpoint of the federation engine that is benchmarked.

      • hookSparqlEndpointSources: Hook[]

        The SPARQL endpoints of the datasets, which are started one by one.

      • endpointUrl: string

        The URL of the SPARQL endpoint of the federation engine.

      • endpointUrlExternal: string | undefined

        The URL to check if the SPARQL endpoint of the federation engine is available.

      • sourceUrlsExternal: string[] | undefined

        The URLs to check if each source is available before starting the next one.

      • queryRunnerReplication: number

        The number of replication runs.

      • queryRunnerWarmupRounds: number

        The number of warmup runs.

      • queryRunnerRequestDelay: number

        The delay between requests in milliseconds.

      • queryRunnerEndpointAvailabilityCheckTimeout: number

        The timeout of the availability check in milliseconds.

      • queryRunnerUrlParams: Record<string, any>

        URL parameters to pass to the SPARQL endpoint.

      • queryTimeoutFallback: number | undefined

        A timeout in milliseconds for a single query, as fallback for the endpoint's timeout.
